## 📌 Overview

**UniCore** is a comprehensive, full-stack web application designed to solve institutional and portal fragmentation. By combining traditional University Management System (UMS) administrative workflows with an engaging Learning Management System (LMS), UniCore delivers a seamless real-time experience for students, faculty members, and administrators alike.

---

## ✨ Key Features

### 🏛️ UMS (Administrative Module)
* **Student & Faculty Portals:** Role-based dashboards tailored for secure data access and management.
* **Enrollment & Registration:** Streamlined course registration, fee tracking, and semester scheduling.
* **Academic Records:** Instant access to transcripts, attendance tracking, and performance metrics.

### 📚 LMS (Learning Module)
* **Course Hub:** Centralized repositories for lecture notes, syllabi, and multimedia resources.
* **Assignment Management:** Real-time submission portals, grading modules, and deadline trackers.
* **Interactive Learning:** Built-in discussion threads and instant announcements between faculty and students.

---

## 🛠️ Tech Stack

* **Frontend:** Next.js (React), TypeScript, Tailwind CSS
* **Backend & Database:** Supabase, PostgreSQL, Row Level Security (RLS)
* **Authentication:** Supabase Auth (Role-based access control)
* **Deployment:** Netlify / Vercel
